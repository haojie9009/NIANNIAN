# 念念追思影像平台 — 表单到分镜的完整数据流

> 最后更新：2026-05-19

---

## 概览

```
用户填写表单（form_data）
  │
  ▼ MV01
  结构化采访 JSON ──────── G1（家属确认）
  │
  ▼ MV02
  校验结论 + 建议时长 ──── G2（家属通过）
  │
  ▼ MV03  ← 分镜制作
  ┌────────────────────────────────────────┐
  │  style_profile      全片色调/转场/基调 │
  │  character_bible    人物 DNA 锚点      │
  │  scene_library      允许场景集合       │
  │  scenes[N]          逐镜：提示词+口播  │
  └────────────────────────────────────────┘
  │
  ▼ MV04
  三大圣经锁定（人物/场景/道具）── G4
  │
  ▼ MV05  AI 画面生成（Comfy/302.ai）
  │
  ▼ MV06  最终剪辑合成
```

---

## 一、表单采集（起点）

用户在念念影像制作页填写以下 12 个字段，保存到 `session.form_data`：

| 字段 | 说明 |
|---|---|
| `deceased_name` | 逝者姓名 |
| `birth_date` | 出生日期 |
| `death_date` | 离世日期（可选） |
| `occupation` | 职业与主要经历 |
| `ceremony_date` | 追思仪式日期 |
| `ceremony_venue` | 仪式场地 |
| `total_duration_sec` | 成片目标时长（秒） |
| `family_memory_text` | 家属记忆叙述（自由文本） |
| `last_wishes` | 遗愿或嘱托 |
| `speaker_name` | 致辞人姓名 |
| `speaker_relation` | 致辞人与逝者关系 |
| `speaker_style` | 致辞风格描述 |

---

## 二、MV01 — 采访结构化

**输入**：`form_data`

**作用**：将自由文本翻译为严格结构化的采访 JSON，供后续步骤精确引用。

**输出 JSON 关键字段**：

```json
{
  "interview_status": "completed",
  "interview_mode": "deep_mode",
  "basic_info": {
    "name": "陈文斌",
    "birth_date": "1948-10-15",
    "death_date": "2025-04-08",
    "age": 76,
    "display_title": "永远怀念"
  },
  "core_memories": [
    {
      "content": "1978年高考恢复后，以全公社唯一考上大学的知青身份进入上海工业大学",
      "emotion": "proud",
      "time_period": "youth",
      "related_assets": ["photo_01"]
    }
  ],
  "uploaded_assets": [
    { "asset_id": "photo_01", "type": "portrait", "description": "近景肖像", "time_period": "2010s" }
  ],
  "style_preference": "warm_nostalgia",
  "emotional_intensity": "moderate",
  "speaker_profile": {
    "name": "陈明",
    "relation": "儿子",
    "style": "深情克制，儒雅温暖，感恩回望，不过度煽情"
  }
}
```

> **🔒 人类闸门 G1**：家属确认这份结构化采访稿后，方可进入 MV02。  
> 支持局部循环：可只修改单条记忆或单个字段，无需重跑全部。

---

## 三、MV02 — 信息校验

**输入**：MV01 输出

**作用**：检查素材是否满足成片最低要求，给出补全建议与可读总结。

**输出 JSON**：

```json
{
  "status": "ready",
  "can_skip_optional": true,
  "target_duration_sec_suggestion": 300,
  "summary_for_human": "已具备肖像与4条核心记忆，建议补充语音样本以提升声音克隆质量。",
  "prompts": []
}
```

- `status` = `ready`：可进入分镜；`needs_input`：`prompts` 中会列出缺失项。
- `target_duration_sec_suggestion` 会传给 MV03 作为分镜时长基准。

> **🔒 人类闸门 G2**：家属对校验结论表态"通过"，方可进入 MV03。

---

## 四、MV03 — 分镜制作（核心）

**输入**：MV01 + MV02 全部输出

**作用**：一次性生成完整的视频级叙事模板——分镜结构、AI 作图提示词、口播文稿。

---

### 4.1 `style_profile` — 全片风格档案

```json
{
  "style_id": "warm_nostalgia",
  "emotional_intensity": "moderate",
  "visual_suffix": "vintage 2000s Chinese home video aesthetic, warm golden sunlight, soft focus, nostalgic vibe, realistic texture --v 7",
  "color_palette": ["#FFD700", "#FFF8DC", "#D2B48C", "#8B4513"],
  "tone": "empathetic, gentle, conversational",
  "transition_style": "slow_crossfade"
}
```

所有镜头的 `mj_prompt` 末尾都会拼接 `visual_suffix`，保证全片色调一致。

---

### 4.2 `character_bible` — 人物视觉 DNA

```json
{
  "display_name": "陈文斌",
  "character_dna": {
    "facial_features": "76-year-old Chinese man, deeply wrinkled face, kind gentle eyes behind black-framed glasses, silver-white hair combed back neatly",
    "body_features": "medium build, slightly hunched posture, broad weathered hands with calloused fingers",
    "clothing_style": "dark grey Zhongshan suit, plain white inner shirt, black cloth shoes",
    "mannerisms": "moves slowly and deliberately, quiet dignified presence"
  }
}
```

> 这是所有镜头人物形象的唯一锚点，MV05 画面生成必须严格参照此描述，确保前后帧视觉一致。

---

### 4.3 `scene_library` — 场景库

列出本片允许出现的所有场景，每个场景用英文 `visual_descriptor` 精确描述：

```json
[
  {
    "scene_id": "factory_workshop",
    "scene_name": "上海机床厂车间",
    "visual_descriptor": "1980s Chinese state-owned factory workshop, rows of metal lathes and milling machines, industrial overhead fluorescent lighting, oil-stained concrete floor, workers in blue Mao suits, socialist-era propaganda posters on walls"
  },
  {
    "scene_id": "park_taichi",
    "scene_name": "公园晨练",
    "visual_descriptor": "early morning Chinese urban park, elderly couple practicing Tai Chi, misty golden sunrise light through old trees, dew on grass, peaceful and timeless atmosphere"
  },
  {
    "scene_id": "calligraphy_desk",
    "scene_name": "书法书桌",
    "visual_descriptor": "simple Chinese home study desk, inkstone and brush set, half-finished calligraphy on rice paper, warm desk lamp, bookshelf with worn volumes in background"
  }
]
```

---

### 4.4 `scenes` — 逐镜分镜表（最终交付核心）

每一镜包含以下所有字段：

```json
{
  "scene_id": "scene_01",
  "duration_sec": 35,
  "shot_type": "medium_close_up",
  "description": "开场：公园晨练，陈文斌与妻子的金婚剪影",
  "source_type": "ai_generated",
  "source_asset_ref": null,
  "mj_prompt": "elderly Chinese couple in their 70s practicing Tai Chi in a misty morning park, man wearing dark grey Zhongshan suit with black-framed glasses, silver-white hair, woman beside him in blue jacket, golden sunrise light filtering through old trees, soft focus, warm nostalgic atmosphere --ar 16:9",
  "camera_motion": "slow_zoom_out",
  "voice_script": "五十年的清晨，他第一个起来。"
}
```

| 字段 | 用途 |
|---|---|
| `duration_sec` | 该镜时长，所有镜头合计 = `target_duration_sec` ±5s |
| `shot_type` | 景别：`close_up / medium_close_up / medium_shot / wide_shot` |
| `mj_prompt` | 直接用于 AI 作图/生视频的英文提示词 |
| `camera_motion` | 镜头运动：`slow_zoom_in / slow_zoom_out / static / pan_left` 等 |
| `voice_script` | 数字人在该镜播报的中文口播文稿。**25 字以内（5 秒内）**，精炼有感染力，不要长句 |
| `source_type` | `ai_generated`（AI 生成）或 `user_asset`（引用上传素材） |
| `source_asset_ref` | 引用 `uploaded_assets` 中的 `asset_id`，AI 生成时为 `null` |

> **🔒 人类闸门 G3**：家属逐镜审阅提示词 + 口播，全部通过后进入 MV04。  
> 支持按 `scene_id` 单镜驳回，未驳回镜头保持冻结。

---

## 五、MV04 → MV06 简述

| 步骤 | 作用 |
|---|---|
| **MV04** | 在 MV03 基础上锁定三大圣经（人物/场景/道具），生成 `lock_manifest` 版本号，G4 通过后冻结 |
| **MV05** | 调用 Comfy/302.ai，按每镜 `mj_prompt` + `character_bible` 生成图像与视频片段 |
| **MV06** | 将各镜视频片段 + 口播音频 + BGM 最终剪辑合成，输出成片 |

---

## 六、字段流向速查

```
form_data.family_memory_text
  → MV01.core_memories[].content        ← 结构化记忆
  → MV01.core_memories[].emotion        ← 情感标签（warm/proud/tender...）
  → MV01.core_memories[].time_period    ← 时期标签（youth/career/retirement...）

form_data.style_preference + speaker_style
  → MV01.style_preference + emotional_intensity
  → MV03.style_profile                  ← 全片风格

form_data.deceased_name + occupation + 记忆细节
  → MV01.basic_info + core_memories
  → MV03.character_bible.character_dna  ← 人物外貌 DNA
  → MV03.scenes[].mj_prompt             ← 注入每帧提示词

form_data.total_duration_sec
  → MV02.target_duration_sec_suggestion
  → MV03.target_duration_sec
  → MV03.scenes[].duration_sec 分配     ← 各镜时长之和

form_data.speaker_style + core_memories[].content
  → MV03.scenes[].voice_script          ← 口播文稿
```

---

## 七、注意事项

1. **MV03 与 MV04 映射互换**：`service_manager.py` 中 `MV_FILES` 里 MV03 对应 `MV04-bible-lock.md`，MV04 对应 `MV03-storyboard.md`，这是故意设计（先做分镜再锁定圣经），注意不要混淆文件名与步骤序号。
2. **`negative_prompt` 全局一份**：反向提示词放在 MV03 输出的顶层，不重复写进每一镜。
3. **`source_asset_ref` 优先**：若家属上传了对应时期照片，`source_type` 改为 `user_asset`，`mj_prompt` 可留空或作辅助参考。
4. **G 闸门阻断**：`gate_manager.can_run()` 会检查前置步骤是否 `approved`，未通过则 API 返回 403，前端不会错误触发下一步。
