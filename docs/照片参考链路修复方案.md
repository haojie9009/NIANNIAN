# 照片参考链路修复方案（V2）

## 问题描述

`memorial.html` Step 2 上传照片后，`/pipeline/scene/image` 生成图片时没有参考上传的照片。

更关键的是，现有设计缺少对以下场景的处理：
- 如何知道照片是逝者的？
- 如果有多个人的合照怎么办？
- 如果有多张照片（不同时期）+ 视频，如何匹配到对应分镜？

---

## 根因分析

### 当前数据流（断裂）

```
memorial.html Step2 上传照片
  → POST /assets/upload → session["assets"]（仅存 url/filename/period="default"）
  → gen_scene_image() → generate_image_302(prompt)    ← reference_b64 始终为空
```

**断裂点**：
1. `studio.js:204` 调用时发送 `{}`，不传任何照片信息
2. `gen_scene_image()` 不读 `session["assets"]`
3. `generate_image_302()` 已支持 `reference_b64`，但没被传入

### 已有能力（可以复用）

- `describe_image(image_bytes)` — 图像内容理解（`llm_client.py:498`），可识别照片中人物
- `period` 字段已在 assets 结构中存在，但前端始终传 `"default"`
- `generate_image_302(prompt, reference_b64)` — 已支持有参考照片的图生图

---

## 核心设计原则

在追思场景中，照片的归属比通用场景更重要。设计原则：

1. **上传时标记，使用时匹配** — 不靠后端猜，而是在用户上传时就标记
2. **AI 辅助识别，人工确认** — `describe_image` 辅助判断，但最终由用户确认
3. **时期对应** — 青年照片用于青年场景分镜，不混用

---

#### 1.3 后端：`service_manager.py` — 智能匹配参考照片

**文件**：`backend/services/service_manager.py`

```python
def _select_reference_photo(s: dict, scene: dict, scene_idx: int) -> Optional[str]:
    """根据分镜内容和场景时期，从用户上传的照片中选择最合适的一张作为参考。

    优先级：
    1. 分镜中明确指定的照片（通过 scene["_reference_photo"] 由前端指定）
    2. 根据分镜时期自动匹配（如"年轻时"→ period_label="青年" 的照片）
    3. subject="deceased" 的第一张照片
    4. 任意照片（如果没有逝者照片）
    """
    assets = s.get("assets", [])
    photos = [a for a in assets if a.get("filename", "").lower().endswith(
        ('.jpg', '.jpeg', '.png', '.webp', '.gif'))]
    # 注意：只过滤图片，不包含视频（.mp4/.mov/.m4a/.wav/.mp3 等）
    # 视频用于最终合成，但不作为生成分镜图片的参考

    if not photos:
        return None

    # 1. 前端指定
    specified = scene.get("_reference_photo")
    if specified:
        match = next((p for p in photos if p.get("url") == specified), None)
        if match:
            return match["saved_as"]

    # 2. 时期匹配（MV04 分镜中的 visual/scene_desc 可能包含时期线索）
    scene_desc = (scene.get("description") or scene.get("visual") or "").lower()
    period_keywords = {"青年": ["青年", "年轻", "大学", "青春", "插队"],
                       "中年": ["中年", "工作", "车间", "技术", "工程师"],
                       "老年": ["老年", "退休", "晚年", "白发", "白发苍苍"]}

    for label, keywords in period_keywords.items():
        if any(kw in scene_desc for kw in keywords):
            match = next((p for p in photos if p.get("period_label") == label
                          and p.get("subject") == "deceased"), None)
            if match:
                return match["saved_as"]

    # 3. 默认：逝者的第一张照片
    deceased_photo = next((p for p in photos if p.get("subject") == "deceased"), None)
    if deceased_photo:
        return deceased_photo["saved_as"]

    # 4. 兜底：第一张照片
    return photos[0]["saved_as"]
```

async function genSceneImage(idx) {

### 第三阶段：多人物 / 合照处理（后续迭代）

**问题**：合照中有多人，AI 不知道谁是需要保留面部特征的"主角"。

**方案**：

1. **前端交互**：用户点击合照，框选/标注"这是逝者"
2. **后端处理**：
   - 用 `describe_image` 识别合照中的人物描述
   - 在 `generate_image_302_ref` 的 prompt 中加入：
     ```
     请参考图中[被标记/居中/戴眼镜]的人物（即逝者陈文斌），
     严格保留其面部特征...
     ```
3. **或者**：使用人脸裁剪/分割技术，将合照中的人物单独提取后再作为参考

**存储扩展**：

### 第四阶段：视频参考（后续迭代）

**问题**：用户上传的是视频而非照片。

**方案**：

1. 上传视频时，提取关键帧（第 1 秒、中间、结尾各取一帧）
2. 每帧作为一张参考图存储，带 `period_label`
3. 生成时从关键帧中选择最匹配的

```python
def extract_video_keyframes(video_path, count=3) -> List[Path]:
    """从视频中提取关键帧图片"""
    import cv2
    cap = cv2.VideoCapture(str(video_path))
    total_frames = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
    step = total_frames // (count + 1)
    frames = []
    for i in range(1, count + 1):
        cap.set(cv2.CAP_PROP_POS_FRAMES, step * i)
        ret, frame = cap.read()
        if ret:
            path = UPLOADS_DIR / f"{sid}_frame_{i}.jpg"
            cv2.imwrite(str(path), frame)
            frames.append(path)
    cap.release()
    return frames
```

   - 青年场景是否参考了青年照片
   - 中年场景是否参考了中年照片
   - 合照是否没有被错误用作单人参考
